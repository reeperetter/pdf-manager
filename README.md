# PDF OCR & Перекладач

Програма з GUI (Tkinter, Python 3.12) для розпізнавання тексту в PDF
(скани / фото-сторінки) та створення:

1. **Розпізнаваного PDF** — виглядає точно як оригінал, але текст можна
   виділяти, копіювати та шукати (Ctrl+F).
2. **Перекладеного PDF (українською)** — той самий макет і картинки,
   але текст замінено на переклад, вставлений прямо на місце оригіналу.
3. **Перекладеного PDF (російською)** — аналогічно.

Розпізнавання тексту працює на **EasyOCR** — це чиста Python-бібліотека.
На відміну від Tesseract, тут **не потрібно нічого ставити окремо через
apt/dnf/brew** — усе встановлюється одним `pip install`, і працює
однаково на Windows / macOS / Linux (зокрема на Nobara/Fedora, де пакети
`tesseract-ocr-ukr` тощо часто відсутні в репозиторіях).

## 1. Встановлення

```bash
pip install -r requirements.txt
```

Це встановить: `pymupdf`, `numpy`, `pillow`, `easyocr`, `deep-translator`.

⚠️ **easyocr тягне за собою PyTorch** — перше встановлення може зайняти
кілька хвилин і кілька сотень МБ на диску. Це плата за те, що більше
нічого не потрібно ставити окремо на кожному комп'ютері.

### Перший запуск для кожної мови

При першому розпізнаванні з певним набором мов (наприклад,
українська+російська+англійська) EasyOCR автоматично завантажує
модель (~50–100 МБ) у папку `~/.EasyOCR/model`. Це відбувається **один
раз** — потрібен інтернет тільки при першому запуску з цим набором мов,
далі розпізнавання працює повністю офлайн.

### Шрифт з кирилицею

Програма постачається разом із файлом `DejaVuSans.ttf` — переконайтеся,
що він лежить **в тій самій папці**, що й `pdf_ocr_translator.py`.
Тоді нічого додатково налаштовувати не потрібно. За бажання можна
вказати інший TTF-шрифт у полі GUI.

### Інтернет для перекладу

Переклад (Google Translate через `deep-translator`) завжди працює через
інтернет. Розпізнавання (OCR) після першого завантаження моделі працює
повністю офлайн.

## 2. Запуск

```bash
python pdf_ocr_translator.py
```

## 3. Використання

1. Додайте один або декілька PDF-файлів (кнопка "Додати файли..." або
   "Додати папку..."). Діалог вибору файлів за замовчуванням відкривається
   в корені диска, а надалі запам'ятовує останню відкриту вами папку.
2. У розділі 2 позначте мову(и) оригіналу для розпізнавання (за
   замовчуванням увімкнені всі три — українська, російська, англійська;
   можна лишити тільки потрібні для трохи вищої швидкості й точності).
3. Позначте, що треба створити: розпізнаваний PDF та/або переклади.
4. Виберіть папку для результатів.
5. Натисніть "Почати обробку". Прогрес і повідомлення видно в журналі
   внизу вікна — включно з детальними повідомленнями про помилки, якщо
   щось піде не так.

Результати зберігаються як:
- `назва_файлу_searchable.pdf`
- `назва_файлу_uk.pdf`
- `назва_файлу_ru.pdf`

## 4. Обмеження та поради

- Якість розпізнавання залежить від якості сканів. Рекомендований DPI:
  250–300 для звичайних сканів, 300–400 для дрібного шрифту.
- Розпізнавання на CPU (без GPU) для великих багатосторінкових файлів
  може бути повільним (кілька секунд на сторінку) — це нормально для
  EasyOCR. Якщо у вас є відеокарта NVIDIA з підтримкою CUDA і
  встановлений відповідний PyTorch з підтримкою GPU, позначте
  "Використовувати GPU" для значного прискорення.
- Переклад вставляється рядок-в-рядок на місце оригіналу з
  автопідбором розміру шрифту під ширину рядка. Якщо переклад значно
  довший за оригінал (типово для перекладу на слов'янські мови),
  шрифт може стати помітно дрібнішим за рядок — це очікувана поведінка
  при збереженні точного макета.
- Фон під перекладеним текстом визначається автоматично (колір біля
  рядка), тому на кольорових / складних фонах заміна тексту може
  виглядати не ідеально акуратно.
- Переклад використовує безкоштовний Google Translate endpoint через
  бібліотеку `deep-translator`; при дуже великій кількості сторінок
  можливі тимчасові обмеження швидкості з боку Google — у такому разі
  програма автоматично перекладає рядок за рядком повторно.

## 5. Усунення несправностей

- **"Не вистачає пакетів"** при запуску — виконайте
  `pip install -r requirements.txt` в тому самому Python-оточенні,
  яким запускаєте скрипт.
- **Нічого не з'являється у вихідній папці** — перевірте журнал у
  вікні програми: усі помилки (включно з повним traceback) виводяться
  туди текстом, а не ховаються мовчки.
- **Не знайдено шрифт з кирилицею** — переконайтеся, що файл
  `DejaVuSans.ttf` лежить поруч зі скриптом, або вкажіть свій шрифт
  вручну в полі GUI.
